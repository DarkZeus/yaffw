Use case: ui-mockup
Asset type: high-fidelity north-star composition for a desktop web media editor
Primary request: Create composition C for YAFFW, a local-first single-asset media editor used for quick occasional desktop edits. The committed visual direction combines DaVinci Resolve's working density, Final Cut Pro's spatial calm, and CapCut Desktop's immediate simplicity. This option is CapCut-simple without feeling consumer-toy-like: obvious workflow, very low chrome, one active media file, quick selection and export.
Structure in order: a slim 42px top bar with YAFFW and the current local file at left, three plain workflow steps Media, Audio, Export centered as flush text tabs, and WebCodecs, Close file, plus one clear teal Export media button at right; below, a large centered Preview viewer taking most of the upper area with a very narrow right properties rail showing only the active task; a small transport row attached beneath the preview with play, timecode, volume; a lower Selection timeline spanning full width with large easy-to-grab teal in/out handles, matching thumbnail strip, stereo waveform, red playhead, selection duration, zoom and Reset. The properties rail is currently on Media and shows only concise file facts, Output choice and Requirements as flat rows. No left sidebar, no project bins, no modal, no card stack.
Visual design: high-fidelity production UI comp, straight-on 1536x1024 landscape, no browser/device chrome. Dark graphite editor, not pure black: #111516 ground, #181E1F panels, #242C2D raised controls, #D8E2E0 primary text, #82908D muted text, deep teal #22A79B for Selection, progress, waveform and active states; red only for playhead/destructive. Flat matte surfaces, precise 1px separators, 4px control corners, no rounded panel shells. Compact contemporary grotesk UI type and monospaced timecode. Icons are simple line icons. Make the task sequence immediately legible but not wizard-like.
Real UI copy only: YAFFW, Media, Audio, Export, Preview, Selection, Reset, WebCodecs, Output, Requirements, Result, Close file, Export media, Playhead, Duration. Use a real-looking but synthetic cinematic landscape video still in the preview and matching thumbnails; do not add multiple media assets, bins, effects libraries, source/program monitors, project tracks, invented capabilities, or claims.
Interaction cues: Media is active; the right rail shows the current file, dimensions and duration in concise rows and a simple Output selector; Audio and Export are one click away; one obvious Export media action; selection range and handles are visually unmistakable; playback is obvious to a first-time user. Keep the interface professional and dense only where manipulation demands it.
Avoid: block inside block inside block, card grids, bento layout, AI dashboard styling, glass, glow, gradients, glossy effects, giant padding, excessive badges, decorative status chips, multi-asset NLE chrome, playful stickers, social-media templates, illegible microtext, random lorem ipsum, watermark.
