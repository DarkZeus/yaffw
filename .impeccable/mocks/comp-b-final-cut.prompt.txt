Use case: ui-mockup
Asset type: high-fidelity north-star composition for a desktop web media editor
Primary request: Create composition B for YAFFW, a local-first single-asset media editor used for quick occasional desktop edits. The committed visual direction combines DaVinci Resolve's working density, Final Cut Pro's spatial calm, and CapCut Desktop's immediate simplicity. This option is Final Cut–calm: the active media itself dominates, with a quiet contextual inspector and a direct selection timeline.
Structure in order: a slim 42px top bar with YAFFW and current local file at left, compact tool/view controls centered, WebCodecs/runtime and a strong but restrained Export media button at right; below, a very large central Preview viewer occupying roughly 72–76% of the upper work area; a contextual right inspector occupying 22–24% with three compact flush tabs Media, Audio, Export and only the selected tab’s controls visible; one slim transport strip visually attached to the viewer; a lower Selection timeline spanning the full application width with matching video thumbnail strip, stereo waveform lanes, red playhead, teal in/out selection handles, duration, zoom and Reset. No persistent left sidebar. Work regions meet at crisp dividers and do not sit inside rounded cards.
Visual design: high-fidelity production UI comp, straight-on 1536x1024 landscape, no browser/device chrome. Dark graphite editor, not pure black: #111516 ground, #181E1F panels, #242C2D raised controls, #D8E2E0 primary text, #82908D muted text, deep teal #22A79B for Selection, progress, waveform and active states; red only for playhead/destructive. Flat matte surfaces, precise 1px separators, 4px control corners, no rounded panel shells. Compact contemporary grotesk UI type and monospaced timecode. Icons are simple line icons. Spatial calm comes from hierarchy and alignment, not huge empty padding.
Real UI copy only: YAFFW, Media, Audio, Export, Preview, Selection, Reset, WebCodecs, Output, Requirements, Result, Close file, Export media, Playhead, Duration. Use a real-looking but synthetic cinematic landscape video still in the preview and matching thumbnails; do not add multiple media assets, bins, effects libraries, source/program monitors, project tracks, invented capabilities, or claims.
Interaction cues: active Audio tab in the right inspector with included audio track, volume fader and small meter; centered playback controls; one obvious Export media action; selection range is dominant and directly manipulable in the lower timeline. File facts are concise and subordinate.
Avoid: block inside block inside block, card grids, bento layout, AI dashboard styling, glass, glow, gradients, glossy effects, giant padding, excessive badges, decorative status chips, multi-asset NLE chrome, illegible microtext, random lorem ipsum, watermark.
