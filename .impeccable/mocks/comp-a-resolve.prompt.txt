Use case: ui-mockup
Asset type: high-fidelity north-star composition for a desktop web media editor
Primary request: Create composition A for YAFFW, a local-first single-asset media editor used for quick occasional desktop edits. The committed visual direction combines DaVinci Resolve's working density, Final Cut Pro's spatial calm, and CapCut Desktop's immediate simplicity. This option is Resolve-balanced: professional but stripped to only YAFFW's real single-asset workflow.
Structure in order: a slim 42px top bar with YAFFW at left, current local file facts and media-time summary centered, WebCodecs/runtime and Close file at right; below, a compact left inspector occupying 20% width with three flush tabs Media, Audio, Export and no cards inside; a large central preview viewer occupying the upper-right area; one slim transport strip directly under the viewer; a lower Selection timeline spanning the central/right width with video thumbnail strip, waveform lanes, playhead, selection handles, zoom and reset. The inspector and timeline are edge-to-edge work regions separated by crisp rules, never nested cards. Export state is integrated into the Export tab, not a modal stack.
Visual design: high-fidelity production UI comp, straight-on 1536x1024 landscape, no browser/device chrome. Dark graphite editor, not pure black: #111516 ground, #181E1F panels, #242C2D raised controls, #D8E2E0 primary text, #82908D muted text, deep teal #22A79B for Selection, progress, waveform and active states; red only for playhead/destructive. Flat matte surfaces, precise 1px separators, 4px control corners, no rounded panel shells. Compact contemporary grotesk UI type and monospaced timecode. Icons are simple line icons.
Real UI copy only: YAFFW, Media, Audio, Export, Preview, Selection, Reset, WebCodecs, Output, Requirements, Result, Close file, Export media, Playhead, Duration. Use a real-looking but synthetic landscape video still in the preview and matching thumbnails; do not add multiple media assets, bins, effects libraries, source/program monitors, project tracks, invented capabilities, or claims.
Interaction cues: active Audio or Media tab; clear play button; included audio track with volume fader and meter; one obvious Export media action in the Export tab; selection range is visually dominant in the lower surface.
